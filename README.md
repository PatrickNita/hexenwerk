# HEXENWERK Site

Next.js site for HEXENWERK TOBACCO — dark industrial brutalist brand showcase.

## Stack

- Next.js (App Router)
- TypeScript
- ESLint
- Tailwind CSS
- Geist (Vercel)

## Local development

```bash
npm run install:all
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production check

```bash
npm run install:all
npm run build
npm run start
```
